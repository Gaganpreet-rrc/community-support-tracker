## Project Overview

This is a group project to develop key components that could enhance PiXELL River Financial's community engagement. The group project focuses on three main components: the Donation Tracker, Volunteer Hours Tracker, and Event Signup, which streamline the management and tracking of charitable contributions, employee volunteer efforts, and event participation, helping the company better demonstrate its positive impact on the community.
